Коротко

Главная / Проверка / Домен по IP Узнать домен по IP можно обратным запросом к DNS: команда nslookup или dig -x возвращает PTR-запись, если владелец адреса её настроил. Один IP часто обслуживает десятки сайтов, поэтому PTR чаще называет хостера, а не конкретный сайт. Обратный запрос dig -x адрес +short вернёт имя из PTR-записи.

Конспект по разделам

Как узнать домен по IP через PTR-запись: nslookup, dig и host

PTR это запись обратной зоны: она связывает адрес с именем, в обратную сторону по сравнению с A-записью. Её настраивает владелец блока адресов, то есть хостинг-провайдер, а не владелец сайта. Ответ выглядит как static.203-0-113-25.hoster.example. или как нормальное имя сервера.

Какие сайты размещены на IP: сертификат и базы DNS

Если PTR не помог, имена сайтов можно прочитать в TLS-сертификате: при подключении по порту 443 сервер показывает, для каких доменов он выпущен. Метод работает, когда сервер отдаёт сертификат без указания имени. Если на адресе много сайтов, он покажет сертификат по умолчанию, а не все.

Чей IP-адрес: Whois адреса и контакт для жалоб

Whois работает и для адресов. Он называет сеть, организацию и контакт для обращений. Адреса Европы, России и Ближнего Востока выдаёт реестр RIPE NCC.

Вопросы и ответы

Как узнать домен по IP, если PTR-записи нет?

Посмотрите имена в TLS-сертификате сервера, сделайте Whois адреса и проверьте сервис обратного поиска по IP. Полного списка сайтов на адресе это не даст.

Как узнать владельца домена, если известен только IP-адрес?

Сначала найдите имя сайта по PTR или сертификату, затем выполните Whois по имени. Whois по самому адресу покажет провайдера, а не владельца сайта.

Как узнать домен своей почты и чем он отличается от домена сайта?

Домен почты стоит после знака @. Он может совпадать с сайтом или быть другим, а принимающие письма серверы показывает запись MX.

Как узнать домен компьютера в Windows и это то же самое, что сайт?

Нет, это домен Active Directory. Узнать его можно командой PowerShell, а если ПК не в организации, ответом будет WORKGROUP.

Можно ли узнать пароль домена?

Нет. У доменного имени пароль задаёт владелец у регистратора, и сбрасывается он только через регистратора. Пароль учётной записи Windows сбрасывает администратор.
