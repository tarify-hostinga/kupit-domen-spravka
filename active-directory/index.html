Active Directory: домен, каталог и объекты, коротко и с данными

Конспект страницы: 6 разделов коротко, данные на 19 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Active Directory: домен, каталог и объекты.

Коротко

Главная / Домен Windows / Active Directory Active Directory домен это каталог Microsoft, где хранятся учетные записи пользователей, компьютеры и группы сети, а контроллеры домена проверяют вход и отвечают на запросы по протоколу LDAP. Служба, которая за это отвечает, называется доменными службами Active Directory, AD DS. Active Directory это база объектов сети, то есть пользователей, компьютеров и групп, плюс служба проверки входа.

Конспект по разделам

Что такое Active Directory и что хранит домен

Каталог это иерархическое хранилище данных об объектах сети. По описанию Microsoft, AD DS хранит сведения о пользователях, компьютерах, принтерах и общих ресурсах и позволяет авторизованным пользователям их находить (источник: обзор доменных служб Active Directory, проверено 19 октября 2026). Вход и права доступа встроены в сам каталог.

Какие объекты хранит Active Directory

У каждого объекта есть уникальное составное имя, по которому его находят в каталоге. Читается оно слева направо от конкретного к общему: Здесь CN это имя объекта, OU подразделение, DC части имени домена. Список объектов можно листать в «Пользователях и компьютерах Active Directory» ( dsa.msc ) или командой Get-ADUser -Filter *.

Как работают LDAP и Kerberos в домене Active Directory

К каталогу обращаются по протоколу LDAP: через него программы ищут пользователей, читают атрибуты и проверяют принадлежность к группам. Порт LDAP 389, с шифрованием 636, а для глобального каталога 3268 и 3269. Список портов сверен с документацией Microsoft (проверено 19 октября 2026), полная таблица лежит на странице про контроллер.

Что значит «доменные службы Active Directory сейчас недоступны»

Сообщение появляется, когда компьютер не смог связаться с контроллером домена. Типичный случай: открыть окно поиска принтера в каталоге и увидеть, что доменные службы Active Directory сейчас недоступны. Причины сводятся к нескольким: на компьютере указан чужой DNS, нет связи с офисной сетью (ноутбук вне офиса), закрыты порты, контроллер выключен или часы разошлись.

Как установить доменные службы Active Directory

Роль AD DS ставят на Windows Server одной командой, после чего сервер повышают до контроллера домена: Нужен сервер со статическим адресом, постоянным именем и паролем режима восстановления. Для лаборатории подойдёт арендованный Windows-сервер, ориентир редакции: 2 vCPU и 4 ГБ памяти. Все шаги и проверки: установка контроллера домена.

Вопросы и ответы

Что такое домен Active Directory?

Это группа компьютеров и пользователей, которыми управляют контроллеры на общей базе каталога. Вход и права проверяет сервер, а не отдельный компьютер.

Что значит, что доменные службы Active Directory недоступны?

Компьютер не может связаться с контроллером домена. Проверьте, что DNS указывает на контроллер, сервер включён, а порты 53, 88, 389 и 445 не закрыты.

Почему принтер пишет, что доменные службы Active Directory сейчас недоступны?

Поиск принтера идёт через каталог, а компьютер не видит контроллер. Исправьте DNS и связь с сетью или добавьте принтер по сетевому пути \\сервер\принтер.

Чем протокол LDAP отличается от Kerberos в Active Directory?

LDAP отвечает за запросы к каталогу (поиск и чтение объектов), Kerberos за проверку входа и выдачу билетов доступа. Порты 389 и 88 соответственно.
