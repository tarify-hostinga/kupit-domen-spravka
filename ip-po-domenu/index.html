Главная / Проверка / IP по домену Узнать IP по домену можно запросом к DNS: команда nslookup или dig возвращает A-запись с IPv4-адресом и AAAA-запись с IPv6, на которые указывает имя. Занимает это несколько секунд и не требует доступа к самому сайту. Выполните nslookup example-site.ru и возьмите строку Address: это и есть IP, на который сейчас указывает домен.

Конспект по разделам

Как узнать IP по домену командой nslookup

Команда nslookup есть в Windows, Linux и macOS. Введите её с именем домена. Адреса в примерах взяты из диапазона для документации, а ваш ответ покажет настоящие.

Как узнать IP сайта по домену через dig и PowerShell

Утилита dig даёт чистый ответ без лишних строк. В Windows её нет, вместо неё работает командлет PowerShell. Адрес видно и в ответе ping: он стоит в квадратных скобках после имени.

Что значат A и AAAA, когда вы узнаёте IP по домену

Вопросы и ответы

Как узнать IP по домену онлайн, если нет командной строки?

Используйте веб-форму DNS-проверки у регистратора или в сервисах диагностики сети. Они выполняют тот же запрос A и AAAA и показывают адреса списком.

Можно ли узнать IP сайта по домену, если он за Cloudflare?

Вы увидите адрес сети Cloudflare, а не сервера сайта. Это защитный механизм, и открытый DNS-запрос настоящий адрес не раскрывает.

Почему nslookup показывает разные IP при повторном запросе?

У домена несколько A-записей или он обслуживается балансировщиком. Порядок и набор адресов меняются, и это не ошибка.

Как узнать информацию о домене помимо IP?

Whois даёт регистратора, даты и NS-серверы, а DNS-запросы дают почту (MX) и текстовые записи. Все способы собраны в разделе проверки домена.
