Коротко

Домен.io это национальная зона Британской территории в Индийском океане, код IO по стандарту ISO 3166. Она открыта владельцам из любых стран, не требует идентификации через Госуслуги и популярна у разработчиков, потому что io знакомо программистам как input/output. Домен.io выбирают стартапы, API и инструменты для разработчиков: адрес выглядит технологично.

Конспект по разделам

Чей домен.io и какой стране он принадлежит

В отличие от.com и.org, зона.io страновая: её двухбуквенный код IO закреплён за Британской территорией в Индийском океане. По записи в базе IANA, зону ведёт компания Internet Computer Bureau Limited из британского Оркпингтона (графство Кент), а продают домены аккредитованные регистраторы. Как коды стран превращаются в доменные зоны и чем они отличаются от общих, разобрано на странице домены стран.

Почему домен.io любят разработчики и стартапы

Сочетание букв io в программировании знакомо всем: так сокращают input/output, ввод и вывод данных. Поэтому адреса вида «название.io» стали привычными для API, библиотек, облачных сервисов и стартапов. Зона не создавалась для технологий.

Нужно ли быть резидентом, чтобы зарегистрировать.io

Проживать на территории, к которой привязан код IO, не нужно: регистрировать домен может владелец из любой страны. Подтверждать личность через ЕСИА, как в.ru и.рф, тоже не требуется, достаточно контактных данных владельца. Что учесть в долгосрочном проекте Страновые зоны подчиняются условиям своего реестра, а не общим правилам для.com.
